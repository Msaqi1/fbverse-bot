🧪 Test Objectives & Fixes in v3.7.17-beta

Ready To Test

1. Marketplace Browsing & Listing Location Change

Problem: Meta recently updated the Marketplace filter buttons from "Within" text to City · Radius (with middle dot \u00b7). Furthermore, listing forms require human keystrokes to trigger the React typeahead dropdown.
Test Action: Run "New Account Slow Listings" or "Marketplace Actions" with custom locations (e.g., Houston, Texas or London). Confirm that the location filter opens, types character-by-character, clicks the suggestion dropdown, and applies successfully.

Ready To Test

2. Multi-Browser Concurrency Stability (Anti-Crash & Hang)

Problem: Launching multiple browsers simultaneously caused memory exhaustion and child Chromium exceptions that would close the parent bot GUI.
Test Action: Launch 2 to 4 concurrent browser profiles. Monitor system memory. If an individual browser tab disconnects or closes, confirm that the main FBVerse Bot interface stays completely active, logs cleanly, and does not terminate.

Ready To Test

3. Instant Stop Button (Sub-250ms Termination)

Problem: Clicking the Stop button during heavy automation caused PyQt GUI threads to freeze into "Not Responding" while waiting for synchronous child joins.
Test Action: Start automation on multiple accounts, then click the STOP button. Confirm that the UI immediately resets to IDLE within 250 milliseconds and all orphaned Chrome instances are terminated asynchronously.

Verified

4. License Key Verification & Allowed Versions Check

Status: Google Sheets backend has been verified with Allowed_Versions: 3.7.14, 3.7.15, 3.7.16, 3.7.17. Keys such as FBV-BAN6-KK8K-SLYL authenticate immediately without false update blocks.
