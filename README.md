# FBVerse Bot v3.7.16 • Facebook Marketplace Automation Software

Official distribution repository for **FBVerse Bot v3.7.16**. High-performance Facebook Marketplace bulk listing, drafts publisher, auto-renew, auto-reply engine, and anti-detect stealth browser.

---

## 🚀 Key Features

- **⚡ 37 Automation Scripts:** Pre-compiled and embedded in-memory automation modules for Facebook Marketplace.
- **🛡️ Anti-Detect Stealth Browser:** Isolated Chromium profiles with dynamic canvas, audio, and fingerprint randomization.
- **💬 Auto-Reply Messenger Engine:** Instant keyword-based responses to buyer messages 24/7.
- **🔄 Auto-Renew & Relist:** Automatically bump expired and stale listings to the top of Marketplace feeds.
- **📱 Multi-Device Cloud Licensing:** Real-time Google Sheets license database with instant version control.
- **⚡ Lightweight OTA Micro-Updates:** Existing users receive instant, lightweight patches (~390 KB) without re-downloading the entire software.
- **💻 100% Local Execution:** Runs completely offline on local PC RAM with zero third-party server latency.

## 🛠️ Quick Installation Guide

1. Download **`FBVerse_Bot_Setup_v3.7.16.exe`** (or **`FBVerse_Seller_Setup.exe`** for Seller Edition).
2. Run the installer (accept Administrator prompt when requested).
3. Click **'Install Now'** — the setup automatically installs the certificate, configures hosts redirection, and creates your Desktop shortcut.
4. Launch **FBVerse Bot** from your Desktop, enter your **License Key**, and start automating!
